# Audit artifacts

Runtime reports should be written under:

`.agents/audit/YYYY-MM-DD_HHMMSS/`

Recommended:
- `task.json`
- `impact.json`
- `commands.json`
- `security-gate.json`
- `findings.md`
- `diff.patch`
- `final-report.md`

Do not store private keys, real user messages, credentials or production secrets here.
